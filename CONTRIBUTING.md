# Contributing

Thanks for helping. Read [AGENTS.md](AGENTS.md) first: it holds the rules every change follows.

- Contributions are accepted under the [Apache-2.0](LICENSE) licence (its section 5).
- Sign off each commit (`git commit -s`) to certify the
  [Developer Certificate of Origin](https://developercertificate.org/).
- Every source file starts with `// SPDX-License-Identifier: Apache-2.0`; CI checks it.
- Run `pnpm lint`, `pnpm check:spdx`, `pnpm typecheck`, `pnpm build` and `pnpm test` before you
  open a pull request.
- Report security issues privately to security@kapabl.dev, not in an issue.

This repository is mirrored from Kapabl's main repository. A merged pull request is applied
there and comes back here with its authorship kept.
